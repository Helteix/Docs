# Installation Guide

This page shows you how to install the **Singletons** package.

## Introduction
`com.helteix.singletons` is a free package that provides three flexible ways to work with singletons in your project. You can install it either from the Unity Asset Store or from the [Helteix GitHub page](https://github.com/Helteix).

:::info[Dependency]
Singletons depends on **`com.helteix.tools`**. When you install Singletons through the Package Manager the dependency is resolved automatically. If you install from a Git URL, make sure Tools is present in your project as well.
:::

:::info[Which should I choose?]
It is recommended to stick with the Asset Store version for more stability.
:::

## Installing from the Asset Store
1. Make sure you are logged in to the Unity Editor with the same Unity account you used to get the package.
2. Open the Unity Package Manager (under *Window/Package Manager*).
3. Look up **Helteix-Singletons** in the search bar and click the *install* / *download* button.

## Installing from GitHub
1. Inside the Package Manager, click the *"+"* button, then select *"Add package from git URL"*.
2. Paste the repository URL of the Singletons package and click *add*.

:::tip
Once installed, you can import the ready-to-use **Scene Services** and **Mono Singletons** samples from the package page in the Package Manager.
:::
